About Privacy

Tools that never leave your device

Every tool here runs inside your browser. No file you open is ever sent to a server � you can check that yourself in your browser's network tab.

Convert PDF pages to an editable Word document (.docx) entirely offline.

Convert Word (.docx) files to PDF entirely in your browser. No upload, no file size limit.

Extract tables from a PDF and save them as an Excel workbook (.xlsx) entirely offline.

Convert Excel workbooks to PDF entirely in your browser. No upload, no file size limit.

PDF to CSV
Extract tables from a PDF and save them as a CSV file entirely offline.

Convert CSV files to PDF entirely in your browser. No upload, no file size limit.
PDF to Text
Extract all text from a PDF and save it as a plain text file entirely offline.
PDF Utilities
Add page numbers or a text watermark to a PDF file entirely in this tab.
