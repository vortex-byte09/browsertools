Excel to PDF (.pdf)

Convert Excel workbooks to PDF entirely in this tab. Your file never leaves your device.

Drop Excel files here, or click to choose

How this works

This tool uses SheetJS to read the Excel workbook, converts each worksheet to an HTML table, and then uses jsPDF with the autotable plugin to render those tables into a PDF file. All processing happens locally in your browser — no upload to a server.

Common uses

Sharing Excel reports as PDF for printing or archiving, converting spreadsheets for email attachments, or creating printable versions of financial statements.
