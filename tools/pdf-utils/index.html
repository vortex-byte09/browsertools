PDF Utilities

Add page numbers or a text watermark to a PDF file entirely in this tab. Your file never leaves your device.

Drop PDF files here, or click to choose

How this works

This tool uses the pdf-lib library to load the PDF, then either draws page numbers at the bottom center of each page or draws a semi‑transparent diagonal watermark text across each page. All processing happens locally in your browser — no upload to a server.

Common uses

Adding page numbers to combined PDFs, marking draft documents with a watermark, or preparing PDFs for distribution with subtle branding.
