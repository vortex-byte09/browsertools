How this works

This tool loads the image into an HTML canvas, then re-encodes it using the browser's built-in image encoders (for JPEG, WebP, PNG). You can choose the output format and adjust quality (for JPEG/WebP). The compressed image is offered as a download. No upload to a server occurs.

Common uses

Reducing file size of photos for faster web loading, shrinking screenshots before sharing, or preparing images for email attachments while preserving acceptable quality.
