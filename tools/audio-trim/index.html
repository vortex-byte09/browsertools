Audio Trimmer

Extract a segment from an audio file by setting start and end times. Processing happens entirely in this tab � no upload.

Drop audio files here, or click to choose

How this works

This tool uses ffmpeg.wasm to run FFmpeg in the browser. It extracts the segment between start and end times (or start + duration) and encodes it as an audio file preserving the original format (or you can select output format). All processing happens locally � no upload to a server.

Common uses

Creating ringtones from songs, extracting clips for social media, removing silence from beginnings/ends of recordings, or isolating specific parts of interviews or podcasts.
