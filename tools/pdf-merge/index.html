Merge PDFs

Add files, reorder them, and merge. Your PDFs are read and combined in this tab — none of them are uploaded, so there's no file size limit tied to a server.

Drop PDF files here, or click to choose

How this works

This tool uses pdf-lib, a JavaScript library that reads and writes PDF files directly in the browser. When you add files, they're loaded into memory in this tab; merging copies each page, in the order you set, into one new PDF that's then offered back to you as a download. At no point does a file travel to a server.

Common uses

Combining scanned pages into one document, joining a cover letter with a resume, or assembling a set of reports into a single file before sending it on.
