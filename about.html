About BrowserTools

BrowserTools is a growing set of utilities that run entirely on your own device. No file you open in any tool here is ever sent to a server — the JavaScript already loaded in your tab does all the work, using your browser's own engine.

The project started with a set of PDF and developer tools, and has grown to include media, image, and audio conversion tools as well. The idea behind all of it is simple: everyday file tasks shouldn't require trusting a stranger's server with your documents, photos, or recordings.

Questions, feedback, or requests for a tool that isn't here yet? Reach out at oriscrypt@gmail.com.
